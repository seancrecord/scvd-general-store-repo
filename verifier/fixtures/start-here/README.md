# The quickstart's test evidence

These files are projections of the independent fixture matrix, generated by
`scripts/verifier-start-here.mjs` in the source checkout. The build check refuses
any drift. They are original MIT-licensed synthetic fixtures, not receipts
for a real payment.

`receipt.json` and `receipt-tampered.json` come from the matrix's EdDSA receipt
positive and payload-tamper cases. `receipt-es256.json` is a real ES256-signed
positive that the package must report as unsupported. They retain the source
vector identifiers.

`issuer-key.json` is supplied separately to the verifier, never extracted
from the signed receipt. Its provenance records the source vector and generator
hash. The public key comes from noble's deterministic public test-key generator;
Node/OpenSSL independently checks the original signature. Read the adjacent
[matrix guide](../independent/README.md) for source revisions, implementation
versions and reproduction instructions.

Separate files teach the API boundary, not real trust establishment. Both ship
in this test package. For a real service, you must obtain an authorized key
through independently trusted evidence or policy; neither this fixture nor
a DID lookup authenticates a real merchant. No wallet, private key, credential
or live payment is needed to run the example.
