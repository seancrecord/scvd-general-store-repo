# Candidate signed originals — October 1

The [bounded-review buyer cohort](../research/bounded-source-review-buyer-2026-10-01/REPORT.md) exposed a concrete selection error: a buyer searched the corpus index for a merchant name, found none and concluded no independent signed observation existed. The index links snapshots; the merchant rows live inside their signed claims. Existing prose explains this, but the buyer did not follow the links.

Source version 1.10.0 adds `scvd-evidence sources SAVED_JSON [--subject EXACT_URL]`. It reads a saved corpus index or unsigned host history locally and produces candidate snapshot URLs, input hash and explicit gaps. Index entries are never filtered by merchant text. Host history requires the exact endpoint, including its query, and uses only matching unsigned hints. Unknown input formats are refused. The command does not fetch URLs, import source, write files or verify signatures.

Every result retains `authenticated: false` and `subject_presence: not_checked`, including zero candidates. Invalid, duplicate, unselected and output-omitted rows remain counted. Links are whole, HTTPS, without credentials or fragments; they are still untrusted and not an assertion of safe destinations. Pagination is the supplied response's claim, not archive completeness. Original links must still be deliberately fetched and checked with an independently established key and exact subject. Dates and verdicts from unsigned hints are not printed as observations.

The original-file hash and counts are computed, and output is bounded to the smaller of the command's byte limit and 32 KiB. Existing verification commands and their exit meanings remain unchanged. No runtime dependency or new module is added. The public buyer guide stays on its existing released workflow until the new package is published and read back; README/help describe source availability explicitly.

Four regressions failed before implementation. The tests exercise absent merchant text in an index, exact query-sensitive matching, duplicate/unsafe/malformed links, preserved pagination gaps, whole-link output omission, offline behavior, unchanged input bytes, unsupported inputs and refused verification/write flags. [Controller replay](../research/evidence-source-links-2026-10-01/controller-replay.json) extracts candidate originals from two unchanged archived inputs. This is not a native run or a repair of their scores.

Recipient reporting remains a distinct gap. The generated report already computes the correct identifiers, yet a recipient retyped a digest incorrectly. This change does not claim to prevent that later rewrite. The next reporting mechanism needs its own bounded design and regression witness; another native cohort is not justified by source selection alone.

Release gates: normal PR and all four CI shards, then publication of the exact merged package and clean-install/readback verification before describing the command as available from npm. Preserve earlier experiments and budgets. Fresh capability qualification remains required before any changed native acquisition; buyer, merchant and platform acceptance remain open.
