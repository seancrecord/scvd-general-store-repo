# Bounded source review — October 1

The [previous qualification](../research/source-directories-qualification-2026-10-01/REPORT.md) fetched all six sources successfully but still stopped Claude at the call cap. Its inspection command printed about 78 KB; the host persisted that output outside the neutral workspace and the agent read that path. Preparing an empty folder did not solve the complete workflow.

Explicit `package_review_flow: "bounded-fetch-v1"` requires the existing source-review and prepared-directory conditions. A standalone Node command fetches only the already pinned public source URLs, refuses redirects and existing destinations, streams under a cumulative byte bound, retains exact source bytes, and checks every pin before displaying previews. It never imports or executes fetched code. The complete output is bounded by `PACKAGE_REVIEW_DISPLAY_BYTES`; each untrusted prefix carries source length, displayed bytes and omitted bytes. Unicode prefixes preserve complete code points, including a leading BOM.

The agent still decides what further source slices to read, records remaining review gaps, and chooses whether to proceed or decline. It must read saved workspace files, not host-managed output paths. The exact package install and CLI execution remain separate. Budgets, models, permissions, scoring and offline recipients are unchanged. The initial previews are deliberately partial and do not establish safety or comprehension. This condition removes the prescribed oversized display; it does not enforce a new filesystem sandbox or certify that an agent never reads outside the workspace.

Old plans retain their original prompts and behavior. Qualification remains bound to the complete plan and instrument; old passes cannot authorize the new condition. The script is a controller-supplied source acquisition/inspection aid, explicitly measured in a directed experiment, not organic discovery or an independent security assessment. No source bytes, signature answers or review decision are preloaded. All earlier attempts remain closed and unchanged.

Six controls failed before implementation; the existing plan-binding/permission control passed. Tests cover exact downloads, bounded accountable output, pin/HTTP/size failures, refusal before fetching through an escaped parent, exclusive destinations, hostile Unicode treated as data, cumulative bounds and unchanged permissions/offline prompts. Ten archived prompts reproduce byte for byte without the condition. A separate native qualification is still required; software checks do not establish buyer reliability.
