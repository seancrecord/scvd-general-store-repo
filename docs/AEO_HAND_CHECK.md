# The hand check — eight families, four engines, seven questions

Not a tracker (the keeper, 2026-09-02). A twenty-minute walk, by hand,
on a schedule, written down here so two walks can be compared. The
family list is an outside reviewer's cut (2026-09-03) of the plan's
fifty prompts, and it is the right size.

Checkpoints: **2026-09-17** (two weeks after the crawler, sitemap and
page-type changes went live), **2026-10-15** (six weeks), then
monthly. Engines: ChatGPT (search on), Gemini, Google AI Overviews,
Perplexity.

## The eight queries

| Family | Query | Success looks like |
| --- | --- | --- |
| Branded entity | What is scvd.store? | Correct name, category clause, no July "general store" framing |
| Service category | x402 conformance audit | SCVD named as an option or cited |
| Transaction evidence | How do I verify an x402 payment settled? | Settlement attestation or reconciliation surfaces |
| Receipt verification | How do I verify an x402 signed receipt? | The free conformance desk or /api/verify appears |
| Monitoring | x402 endpoint monitoring signed uptime | Conformance watch or the per-host history appears |
| Dataset | x402 endpoint readiness dataset | /corpus, Zenodo or Hugging Face appears |
| Defect language | offer contradicts challenge x402 | The /defects page wins or is cited |
| Buyer-side testing | test an x402 payment client | /try, good_buyer or the launch check appears |

## The seven questions, per engine, per query

1. Was SCVD named?
2. Was scvd.store cited (a URL in the answer)?
3. Was the description accurate (evidence observatory; independent verification; not escrow, rating or guarantee)?
4. Which URL surfaced?
5. Which competing entity was named first?
6. Did the model conflate us with a trust layer, rating system, payment rail, compliance vendor, or general store?
7. Which exact source did it cite instead of us?
