# The archive

Research passes, process documents, drafts, and logs that shaped the
store but are no longer load-bearing. Nothing here is erased — the
house does corrections, not erasures, and git history holds every
version besides — it has simply stepped back from the front room so
the root directory reads as what the store IS rather than everything
it has ever thought about.

The living documents stay at the root: README (the store), SECURITY
(disclosure), PROBLEMS (the open ledger), PAYMENT_RAILS (the rails
and their gates), AGENT_UX (the walker research), HOUSE_RULES,
AT_SCALE, EMPLOYEES (the cron jobs), REGISTRATION_RUN (the runbook
every future rail repeats), TASKS, and the key-custody pair
(CEREMONY_B, THE_PAPER_KEY).

A document comes back out of the archive by being needed, not by
being missed.
