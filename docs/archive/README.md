# The archive

Research passes, process documents, drafts, and logs that shaped the
store but are no longer load-bearing. Nothing here is erased — the
house does corrections, not erasures, and git history holds every
version besides — it has simply stepped back from the front room so
the root directory reads as what the store IS rather than everything
it has ever thought about.

The living documents stay at the root (list trued up 2026-08-20,
after the documentation audit): README (the store), HOUSE_RULES
(the constitution, with the drift watchlist appended), AGENTS (the
coding-agent contract), KEEPER_LIST (the one desk file — successor
to MONDAY and TASKS, both archived here with their dates; the old
KEEPER_LIST was rewritten in place, git history holds it),
PROBLEMS (the open ledger, its research annex archived here),
SECURITY, NOTICE, CONTRIBUTING, CODE_OF_CONDUCT, AT_SCALE,
PAYMENT_RAILS, REGISTRATION_RUN (the runbook every future rail
repeats), AGENT_UX (the walker research), THE_TAB (spec and flow),
THE_PAPER_KEY (custody; the CEREMONY_B runbook is archived here,
performed 2026-07-31), NOTES_FROM_THE_COUNTER, and the newer papers
RECEIPT_CHAIN, BOUNTY_BOARD, and WALKABOUT.

A document comes back out of the archive by being needed, not by
being missed.
