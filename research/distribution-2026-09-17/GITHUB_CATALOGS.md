## OpenAI and Copilot clarification

[OpenAI's submission guide](https://developers.openai.com/plugins/deploy/submission)
requires a new version/review/publication for skill changes and release notes
explaining the change. Editing the existing plugin to prepare that update is the
right path; a duplicate plugin is unnecessary for adding the matching verifier skill.
The note about not referencing a published integration concerns submission payloads,
not a requirement to discard an existing plugin identity when updating it.

[Awesome Copilot's external-plugin intake](https://github.com/github/awesome-copilot/blob/main/CONTRIBUTING.md#adding-external-plugins)
requires public GitHub source, immutable versioned review material and quality
checks, not prior GitHub MCP Registry or Agent Finder acceptance. Existing
[#3255](https://github.com/github/awesome-copilot/issues/3255) passed intake and
awaits maintainer review. These remain separate channels.
